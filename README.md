# Resume Builder – Web Application

## Overview

Resume Builder is a responsive web application developed using HTML, CSS, and JavaScript that enables users to create professional resumes quickly and efficiently. The project was designed to simplify the resume creation process through a clean, intuitive, and user-friendly interface, allowing users to enter their personal details, education, work experience, skills, and projects in an organized manner.

The application provides a real-time preview of the resume as users update their information, helping them visualize the final output instantly. It also includes customizable resume templates and drag-and-drop functionality for rearranging sections according to user preferences. The project demonstrates my frontend development skills, including responsive web design, DOM manipulation, event handling, and creating interactive user interfaces using core web technologies.

## Features

- User-friendly and intuitive interface
- Multiple resume templates
- Real-time resume preview
- Drag-and-drop section arrangement
- Responsive design for desktop and mobile devices
- Professional resume layout
- Download resume as PDF
- Print-friendly resume format
- Clean and organized code structure
